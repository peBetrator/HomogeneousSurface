# Homogeneous Surface - Астроида

Проект визуализации **конической однородной поверхности** на основе **астроиды** с использованием OpenGL и GLFW.

## 📐 Математическая часть

### Что такое астроида?

**Астроида** (от греч. ἀστήρ — звезда) — это плоская алгебраическая кривая, задаваемая параметрическими уравнениями:

```
x(t) = a · cos³(t)
y(t) = a · sin³(t)
```

где:
- `t` ∈ [0, 2π] — параметр
- `a` — радиус (размер астроиды)

**Декартова форма**: x^(2/3) + y^(2/3) = a^(2/3)

Астроида имеет 4 острых угла (каспы) на осях координат и выглядит как четырёхконечная звезда.

### Однородная коническая поверхность

**Однородная поверхность** (homogeneous surface) — это поверхность, которая получается из плоской кривой путём её масштабирования от одной точки (апекса).

Для астроиды мы строим **двойной конус**:
1. **Верхняя половина**: контур астроиды масштабируется от апекса вверх (z > 0)
2. **Нижняя половина**: контур масштабируется вниз (z < 0)

Математически, если `P(t) = (x(t), y(t), 1)` — точка на контуре астроиды в плоскости z=1, то:
- Точки поверхности: `Q(s, t) = s · P(t) = (s·x(t), s·y(t), s·depth)`
- где `s` ∈ [-L, L] — параметр масштабирования (уровни)
- `depth` — глубина конуса по оси Z

**Уровни (levels)**:
- Отрицательные уровни: s ∈ {-L, -L+1, ..., -1} — нижняя половина конуса
- s = 0 — апекс (вершина конуса)
- Положительные уровни: s ∈ {1, 2, ..., L} — верхняя половина конуса

## 📁 Структура проекта

### Основные файлы

#### `ISurface3D.hpp`
**Интерфейс** для всех 3D-поверхностей.

Определяет:
- `struct Vec3` — трёхмерный вектор (x, y, z)
- Виртуальные методы: `build()`, `draw()`, `vertices()`, `indices()`

#### `AstroidCone.hpp` / `AstroidCone.cpp`
**Базовая геометрия** астроиды без освещения.

**Параметры:**
- `mLevels` — количество уровней масштабирования (кольца от апекса)
- `mSegments` — количество сегментов на контуре астроиды (точность кривой)
- `mDepth` — глубина конуса по оси Z

**Ключевые методы:**
- `generateAstroidContour()` — генерирует точки астроиды по формуле x=a·cos³(t), y=a·sin³(t)
- `build()` — строит всю геометрию (вершины + индексы треугольников)
- `draw()` — рисует поверхность без освещения (простой цвет)

**Алгоритм построения:**
1. Создаётся апекс (0, 0, 0)
2. Генерируются кольца (rings) для каждого уровня s
3. Создаются треугольные веера от апекса к первому кольцу
4. Соединяются соседние кольца четырёхугольниками (2 треугольника)

#### `AstroidConeLit.hpp` / `AstroidConeLit.cpp`
**Астроида с освещением** — наследуется от `AstroidCone`.

Добавляет:
- `mNormals` — массив вершинных нормалей для освещения
- `mWireframe` — флаг отображения каркаса
- `computeVertexNormals()` — вычисляет нормали для каждой вершины
- `draw()` — рисует с материалами и освещением

**Вычисление нормалей:**
1. Для каждого треугольника вычисляется нормаль (перпендикуляр к плоскости)
2. Нормали треугольников суммируются для каждой вершины
3. Результат нормализуется (приводится к единичной длине)

**Материалы:**
- Передняя сторона: фиолетовый (purple)
- Задняя сторона: оранжевый (orange)

#### `CoordinateAxes.hpp` / `CoordinateAxes.cpp`
**Система координат XYZ** с цветными осями и стрелками.

- **X-ось** — красная
- **Y-ось** — зелёная
- **Z-ось** — синяя
- Начало координат — белая точка
- Стрелки на концах осей (конусы через `gluCylinder`)

#### `Background.hpp` / `Background.cpp`
**Фоновое изображение**.

Функции:
- `loadFromExeDir()` — загружает BMP-файл
- `draw()` — рисует текстуру на весь экран (ортогональная проекция)
- Кроссплатформенная загрузка BMP (Windows/macOS/Linux)

#### `Project0.cpp`
**Главный файл** приложения.

Содержит:
- Инициализацию GLFW и OpenGL
- Настройку освещения (3 источника света)
- Главный цикл отрисовки
- Управление камерой (вращение, зум)
- Обработку клавиатуры

## 🔧 Технические детали

### Параметры астроиды

В `Project0.cpp`:
```cpp
static AstroidConeLit gAstroid(12, 64, 3.0f);
```

- **12** — количество уровней (колец)
- **64** — количество сегментов на контуре
- **3.0f** — глубина конуса по Z

### Формулы и алгоритмы

#### 1. Генерация контура астроиды
```cpp
for (int i = 0; i < segments; ++i) {
    float t = (2.0f * M_PI * i) / segments;
    float cost = cosf(t);
    float sint = sinf(t);
    float x = radius * cost * cost * cost;  // a·cos³(t)
    float y = radius * sint * sint * sint;  // a·sin³(t)
    contour.push_back({x, y, 1.0f});
}
```

#### 2. Индекс вершины в кольце
```cpp
unsigned ringIndex(int level, int i) const {
    int L = mLevels;
    int N = mSegments;
    // level=-L...-1 => ordinal=0...L-1
    // level=+1...+L => ordinal=L...2L-1
    int ordinal = (level < 0) ? (level + L) : (level - 1 + L);
    return 1 + ordinal * N + i;
}
```

#### 3. Построение треугольников
```cpp
// Веер от апекса к первому кольцу (нижний)
for (int i = 0; i < N; ++i) {
    mIdx.push_back(apex);                    // 0
    mIdx.push_back(ringIndex(-1, (i+1)%N));  // следующая точка
    mIdx.push_back(ringIndex(-1, i));        // текущая точка
}

// Сшивка двух колец (квад = 2 треугольника)
unsigned v00 = ringIndex(l,   i);
unsigned v01 = ringIndex(l,   (i+1)%N);
unsigned v10 = ringIndex(l+1, i);
unsigned v11 = ringIndex(l+1, (i+1)%N);

mIdx.push_back(v00); mIdx.push_back(v01); mIdx.push_back(v10);
mIdx.push_back(v01); mIdx.push_back(v11); mIdx.push_back(v10);
```

#### 4. Вычисление нормалей
```cpp
// Нормаль треугольника
Vec3 n = cross(B - A, C - A);

// Суммирование в вершинах
mNormals[ia] += n;
mNormals[ib] += n;
mNormals[ic] += n;

// Нормализация
for (size_t i = 0; i < count; ++i) {
    mNormals[i] = normalize(mNormals[i]);
}
```

### Добавление других кривых
Создайте новый класс, наследующийся от `ISurface3D`, и реализуйте метод `generateContour()` с другой параметрической кривой:
- **Круг**: x = r·cos(t), y = r·sin(t)
- **Эллипс**: x = a·cos(t), y = b·sin(t)
- **Кардиоида**: x = a·(2cos(t)-cos(2t)), y = a·(2sin(t)-sin(2t))
- **Лемниската**: ρ² = a²·cos(2θ)

## 🐛 Известные проблемы

1. **Deprecation warnings на macOS**: OpenGL устарел с macOS 10.14, но всё работает. Для подавления предупреждений добавьте:
   ```cpp
   #define GL_SILENCE_DEPRECATION
   ```

2. **Производительность**: При очень большом количестве сегментов (>256) может наблюдаться снижение FPS на старых GPU.
